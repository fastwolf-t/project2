# Документация проекта: Модель интернет-магазина

В данном файле приведено описание архитектуры классов и логики работы модулей интернет-магазина (классы `Product` и `Category`).

## Архитектура классов

### 1. Класс `Product`
Представляет отдельный товар в интернет-магазине.

#### Атрибуты объекта (инстанса):
* **`name`** (`str`): Наименование товара.
* **`description`** (`str`): Подробное описание характеристики товара.
* **`quantity`** (`int`): Количество товара на складе.

#### Свойства (Properties):
* **`price`** (`float`): Геттер для получения приватной стоимости товара (`self.__price`). Сеттер проверяет входное значение: если цена больше `0`, то обновляет её, иначе — выводит предупреждение.

---

### 2. Класс `Category`
Представляет категорию, объединяющую группу товаров.

#### Атрибуты класса (глобальные счетчики):
* **`category_count`** (`int`): Общее количество созданных категорий в системе.
* **`product_count`** (`int`): Общее количество продуктов, добавленных во все категории.

#### Атрибуты объекта (инстанса):
* **`name`** (`str`): Название категории (например, "Смартфоны").
* **`description`** (`str`): Описание товарной группы.

#### Свойства (Properties):
* **`products`** (`str`): Геттер возвращает строковое представление всех добавленных товаров в формате: `Продукт, X руб. Остаток: Y шт.`

---

## Логика инициализации и подсчета данных

### Работа счетчиков при инициализации
1. При создании новой категории через конструктор `__init__` глобальный счетчик категорий `Category.category_count` всегда увеличивается на **`1`**.
2. Внутри конструктора создается приватный пустой список `self.__products: list[Product] = []`.
3. Все переданные при инициализации продукты из списка `products` поочередно добавляются через метод `add_product(product)`.

### Метод добавления продуктов
* **`add_product(product: Product)`**: Добавляет объект товара в приватный список категории и увеличивает глобальный счетчик `Category.product_count` на **`1`** за каждый добавленный товар.

---

## Пример использования программы

Ниже показано, как объекты взаимодействуют с методами и общим состоянием счетчиков при выполнении кода в блоке `__main__`:

```python
# Создание уникальных продуктов
product1 = Product("Samsung Galaxy S23 Ultra", "256GB, Серый цвет, 200MP камера", 180000.0, 5)
product2 = Product("Iphone 15", "512GB, Gray space", 210000.0, 8)
product3 = Product("Xiaomi Redmi Note 11", "1024GB, Синий", 31000.0, 14)

# Инициализация первой категории (счетчики: категорий = 1, продуктов = 3)
category1 = Category(
    "Смартфоны",
    "Смартфоны, как средство не только коммуникации, но и получения дополнительных функций для удобства жизни",
    [product1, product2, product3]
)

# Печать списка товаров через геттер-свойство products
print(category1.products)

# Добавление нового продукта в существующую категорию (счетчики: категорий = 1, продуктов = 4)
product4 = Product('55" QLED 4K', "Фоновая подсветка", 123000.0, 7)
category1.add_product(product4)

print(Category.category_count)  # Выведет: 1
print(Category.product_count)   # Выведет: 4

# Создание продукта через класс-метод фабрику
new_product = Product.new_product({
    "name": "Samsung Galaxy S23 Ultra",
    "description": "256GB, Серый цвет, 200MP камера",
    "price": 180000.0,
    "quantity": 5
})

# Работа валидации в сеттере цены
new_product.price = 800   # Цена изменится на 800
new_product.price = -100  # Выведет: "Цена не должна быть нулевая или отрицательная"
```
